# โครงสร้างโครงการ

- `source-materials/` — หนังสือต้นฉบับและภาพอ้างอิง
- `dist/` — เกมเวอร์ชันพร้อมเล่นและพร้อมเผยแพร่
- `dist/data/levels.js` — question bank/gameplay data ของด่าน
- `dist/forest-map.png` — ภาพฉากหลัก
- `planning/` — roadmap และเอกสารโครงสร้าง
- `.github/workflows/` — automation สำหรับ GitHub Pages

โฟลเดอร์นี้เป็น canonical workspace สำหรับทุก Sprint ถัดไป ตัวละครหลักคือ “แบมแบม (BamBam)”
