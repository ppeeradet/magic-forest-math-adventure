# แผนพัฒนาแบบ Sprint

- Sprint 1–3 (2–3 วัน): ทำ World 1 ให้สมบูรณ์ทั้ง UX, บทสนทนา, animation, audio และ playtest
- Sprint 4–7 (2–3 สัปดาห์): ✅ Core game ขยายเป็น World 1–3 รวม 15 ด่านและฉากจบ โดยใช้คลังโจทย์ 100 ด่านเป็นต้นฉบับ · โปรไฟล์ชาย/หญิงและชื่อกำหนดเอง, save/progress, รางวัล, accessibility, touch target ≥44px และ responsive desktop/mobile/iPad ผ่านการทดสอบ · World 3 เชื่อมจากประตูเห็ดยักษ์ไปสู่นครเห็ด ป่าหมอก หุบเขาดอกไม้ ทะเลสาบเอลฟ์ และป่าต้นไม้นับพัน พร้อมปลายทางสู่นครลอยฟ้า
- Sprint 8–10 (2–4 วัน): 🔄 ฐานระบบบันทึกพร้อมแล้วด้วย save schema v3, migration/repair, timestamp, deterministic conflict merge และ cloud-save adapter ที่ปิดใช้งานโดยค่าเริ่มต้นพร้อม mock online/offline · เพิ่มมุมผู้ปกครองสำหรับสรุปการเรียนรู้และส่งออก/นำเข้าไฟล์สำรองแล้ว · ขั้นถัดไปกำหนด Firebase project/config และ consent flow แล้วจึงเชื่อม cloud save จริง
- Platform readiness: ✅ เพิ่ม PWA manifest, install metadata, ปุ่มติดตั้ง, คู่มือ Add to Home Screen สำหรับ iPhone/iPad, offline asset cache, สถานะออนไลน์/ออฟไลน์ และข้อความแจ้งอัปเดตเวอร์ชันใหม่แล้ว
- World 3 polish: ✅ ด่าน 11–15 ผ่าน full interaction playtest ครบเส้นทาง แก้ปุ่ม “ข้ามเรื่องราว” แล้ว และยืนยันรางวัล ฉากจบ responsive 390×844 / 820×1180 และ console error = 0; ผลทดสอบอยู่ใน `planning/PLAYTEST-WORLD3.md` · เป้าหมายถัดไปทดสอบ reset, keyboard และ reduced motion
- World 4: ✅ ด่าน 16–20 เล่นได้ครบ พร้อมฉากจบรับผลึกหัวใจชิ้นที่ 4 และส่งต่อสู่ “ป่าแห่งความทรงจำ” · regression QA ตรวจลำดับคำนวณ reset, native keyboard buttons, reward, responsive rules และ reduced motion ครบแล้ว · รายละเอียดอยู่ใน `planning/PLAYTEST-WORLD4.md` · เป้าหมายถัดไป specification World 5 ตอนที่ 21–25
- World 5: ✅ ด่าน 21–25 เล่นได้ครบและผ่าน full regression QA แล้ว: exploration, ลำดับคำนวณ, reset, native keyboard, aria-live, reward, save migration, responsive/reduced-motion, แผนที่ 25/25, ฉากจบ 5/10 และทางเชื่อม “ห้องแห่งการคูณ” ตอน 26 ผ่านครบ · รายละเอียดอยู่ใน `planning/PLAYTEST-WORLD5.md` · เป้าหมายถัดไปวาง Story/Gameplay specification World 6
- World 6: ✅ ด่าน 26–30 เล่นได้ครบและผ่าน full regression QA: 6 × 9 = 54, 312 + 249 = 561, 850 − 495 = 355, 7 × 8 = 56 และ 436 + 297 = 733 · มี exploration, reset, native keyboard, aria-live, reward, save migration, responsive/reduced-motion, แผนที่ 30/30 และฉากจบผลึก 6/10 · เป้าหมายถัดไปวาง Story/Gameplay specification World 7 ตอนที่ 31–35 เริ่มที่ “สวนพฤกษาแห่งชีวิต”
- World 7: ✅ ด่าน 31–35 เล่นได้ครบ: รักษาสวน 436, ปลุกนก 40, สร้างสะพาน 633, ซ่อมเวลา 563 และรวมแสงหิ่งห้อย 9 × 7 = 63 พร้อม full regression QA, exploration, reset, native keyboard, aria-live, reward, save migration, responsive/reduced-motion, แผนที่ 35/35 และฉากจบผลึก 7/10 เชื่อม “ทะเลสาบล่องหน” ตอน 36 · เป้าหมายถัดไปวาง Story/Gameplay specification World 8 ตอน 36–40
- World 8: 🚧 ด่าน 36–39 เล่นได้แล้ว: เผยปลาล่องหน 825, ตัดใยเหลือ 524 เมตร, ปลุกต้นคริสตัล 48 ผล และทอความฝัน 547 → 647 → 737 → 745 พร้อม exploration, reset, native keyboard, aria-live, reward, save migration, responsive/reduced-motion และทางเชื่อมหุบเขาเสียงสะท้อน · ด่าน 40 มี specification พร้อม · เป้าหมายถัดไปสร้างด่าน 40 และฉากจบผลึก 8/10
